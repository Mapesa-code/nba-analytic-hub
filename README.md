# NBA Analytics Hub 🏀

A comprehensive web application for NBA analytics featuring game predictions, social sentiment analysis, and highlight videos.

## Features

- **🎯 Game Predictions**: AI-powered game outcome predictions with confidence scores
- **💭 Social Sentiment**: Real-time Lakers sentiment analysis from Reddit posts
- **🎬 Highlights**: NBA highlight video search and playback
- **📈 Analytics**: Performance metrics and feature importance visualization

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Tailwind CSS
- **Charts**: Chart.js
- **Backend**: Node.js + Express
- **Deployment**: Render
